## Description

ft_printf reimplements the standard `printf` function in C using variadic functions and format parsing.

This implementation handles the following conversions: `%c` · `%s` · `%p` · `%d` · `%i` · `%u` · `%x` · `%X` · `%%`

## Installation

```bash
git clone https://github.com/Noemiegrau/printf.git
cd printf/V-Final
make
```
